# Bakery Sales Pipeline

A hands-on data engineering project simulating a real-world sales data pipeline for a fictional bakery chain ("Craquelin"). Built as preparation for an Analytics Engineering role with no existing data infrastructure.

## Goals
- Structured error handling (try/except)
- Logging
- Automated testing (pytest)
- API consumption with retry, auth, and pagination
- Docker containerization

## Stack
Python, pandas, requests, pytest, Docker
